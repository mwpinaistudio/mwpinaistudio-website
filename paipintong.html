Installation

How to install on Android

  1. Tap Download APK on this page.
  2. Open the downloaded file from your browser downloads or Files app.
  3. If Android asks, allow your browser or file manager to install unknown apps.
  4. Tap Install, then open PaiPinTong.
  5. Create or sign in to your PaiPinTong account.
Only download the APK from this official page. If another website asks you to pay or provides a modified APK, delete that file and download again from this page.
Update help

If the APK downloads but does not open

  1. First check the version on this page. Do not install an APK from an unknown source.
  2. Open your browser downloads or the Files app and delete any old or incomplete paipintong.apk.
  3. Return to this official page, tap Download APK again and wait until the download is fully complete.
  4. Tap the downloaded APK. If Android asks, allow install permission for your browser or file manager.
  5. If the install screen still does not appear, delete the downloaded file and repeat the download once more.
