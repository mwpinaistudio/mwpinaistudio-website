How can we help?

For installation problems, account questions, data deletion requests, or privacy concerns, contact the official support email below.

Support email

Please include the app version, Android version, and a short description of the problem. Do not send passwords or private identity documents.

Installation troubleshooting

Android says the APK is blocked

Allow your browser or file manager to install unknown apps, then open the APK again. Only install files downloaded from this official website.

The update will not install

Make sure the new APK uses the same signing key as the version already installed. If it does not, back up your data first and contact support.

I forgot my password

Use the password recovery option in the app. If recovery is unavailable, contact support with your account email.

AI output is incorrect

AI-assisted content is a reference only. Review and edit all product information before publishing or using it.

Data deletion

You can delete products and media in the app. To request deletion of your account and related cloud records, email support from the account address or include enough information to verify ownership. Never send your password.
